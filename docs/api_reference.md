# API Reference

All routes under `/api/v1`. See `/docs` (Swagger) at runtime for full schema.

- health, auth (planned), workspaces (planned)
- datasets: upload, list, get, delete, preview, profile, eda
- dashboards: CRUD, widgets, layout
- visualizations: charts, validate, render
- llm: health, models, chat, command
- agents: query
- analytics: kpi, trend, descriptive, compare-groups, anomalies
- forecasting: train, list
- simulation: scenario, scenarios list, compare, sensitivity
- reports: dataset csv, summary csv, scenarios csv, metadata
